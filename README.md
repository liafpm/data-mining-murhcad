# data-mining-murhcad
This repository contains the assignments and analyses developed for the Data Mining course. 

The project uses the Multi-Regional Cloud Honeynet Dataset (MURHCAD), a cybersecurity dataset containing malicious activity collected through honeypots deployed in Microsoft Azure infrastructure.

## Dataset

### Dataset: Multi-Regional Cloud Honeynet Dataset (MURHCAD)

The dataset contains cybersecurity events such as connection attempts, source locations, ports, protocols, timestamps, and honeypot information.

It includes more than 130,000 records and combines numerical, categorical, geographical, and temporal variables.

## Project Objective

The objective of this project is to apply data mining and statistical techniques to explore patterns in cybersecurity events.

Throughout the course, the project will cover:

1. Data Cleaning
2. Descriptive Statistics
3. Data Visualization
4. Statistical Testing
5. Linear Models and Correlation
6. K-Nearest Neighbors (KNN) Classification
7. K-Means Clustering
8. Time Series Forecasting
9. Text Analysis

## Repository Structure
- data/  
  - raw/          Original dataset  
  - processed/    Cleaned and transformed datasets

- notebooks/  
  - Jupyter notebooks for each course assignment

- outputs/  
   - figures/      Generated visualizations  
   - tables/       Generated tables and results  

The original dataset is preserved without modifications. Cleaned and transformed versions used for subsequent analyses are stored separately in data/processed/.
